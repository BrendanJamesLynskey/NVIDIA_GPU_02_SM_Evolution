# Inside the SM — How NVIDIA's Streaming Multiprocessor Evolved

The Streaming Multiprocessor is the unit-cell of every NVIDIA GPU. Trace its evolution from Pascal's symmetric 64-FP32 design through Volta's independent thread scheduling, Turing's RT cores, Ampere's TF32/BF16, Hopper's tensor-memory accelerator and thread-block clusters, to Blackwell's MX-FP4 5th-generation tensor cores.
